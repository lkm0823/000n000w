# Snow Folio

스노우보드를 타고 설원 스키장 월드를 돌아다니며 작업물을 보는 포트폴리오 웹사이트입니다. 현재 버전은 지형과 보더 이동을 확인하는 프로토타입 v0.3입니다.

## 실행
`index.html`을 크롬으로 열면 됩니다. 인터넷 연결이 필요합니다.

## 조작
| 키 | 동작 |
|---|---|
| W | 밀기 |
| A / D | 회전 (공중에서는 스핀) |
| S | 브레이크 |
| Space | 점프 |
| Shift | 부스트 |
| R | 처음 위치로 |
| Enter | 리프트 타기 (정류장 근처) |
| M | 지도 펼치기 |
| Esc | 일시정지 |
| 마우스 드래그 | 카메라 회전 |

우상단 "조작감 튜닝"에서 중력, 회전 속도, 그립 등을 조절할 수 있습니다.

## 폴더 구성
- `index.html` — 게임 전체(HTML, CSS, JavaScript 한 파일)
